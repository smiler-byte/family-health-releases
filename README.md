# 家庭健康档案 · Android

个人及家庭使用的中文健康档案App，支持Android 10及以上，无需注册账号。

[下载最新版APK](https://github.com/smiler-byte/family-health-releases/releases/latest) · [版本说明](https://github.com/smiler-byte/family-health-releases/releases)

## 安装和更新

下载APK后在手机文件管理器中打开，按安卓提示允许安装。已有版本请直接覆盖安装，保留健康档案；不要先卸载。升级前建议在“我的”导出加密备份。

首次安装0.3.2后，启动时每天最多检查一次新版本，也可在“我的 → 应用更新”手动检查或关闭自动检查。确认下载后显示进度，校验通过再由安卓确认安装；首次需允许本应用安装未知应用。网络无法连接GitHub时可稍后重试。

## 已有功能

- 多患者独立档案、拍照及图片/PDF导入、原件私有保存。
- 本地中文OCR、报告分类与检查日期提取，核对后保存；无法确定的字段供手动确认。
- 医疗时间线、搜索与筛选、报告编辑、原件放大预览。
- 加密备份与恢复、PDF摘要/CSV导出、应用锁和深色模式。

健康数据和OCR在手机上处理。应用更新仅读取公开版本信息和APK，不上传医疗档案。托管平台可以看到请求IP及应用版本。这个仓库仅发布安装包、更新清单和说明，不含私人医疗样本或签名密钥。

目前为个人使用测试版；AI分析、趋势、用药及复查提醒属于后续功能。
